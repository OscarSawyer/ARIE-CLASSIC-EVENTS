# Arie Classic Events image assets

The website now references real image files included in this project. Keep these folder paths intact when editing the site.

- `hero/corporatea-cake-3.jpg` — hero and consultation background
- `cakes/` — cake service photographs
- `events/` — event decoration photographs
- `about/african-baker-consultation2.jpg` — about section image
- `gallery/` — portfolio carousel photographs

Use only photographs the business has permission to publish. Update the corresponding `src` in `../index.html` or background image in `../styles.css` if you rename a file.
